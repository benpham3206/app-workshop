# Playful / Kinetic

Use this recipe when the app should feel energetic and encouraging. Express it through content, an app-specific accent, concise friendly copy, and motion that confirms progress. Keep standard platform controls recognizable.

Before implementation, define semantic colors for applicable appearances and increased contrast, typography for long and short text, motion durations, haptics, icon treatment, and a Reduce Motion equivalent. Test both lively and quiet states; avoid perpetual animation.

## Working grammar

- **Hierarchy:** Show the current job and next action first. Use a vivid accent for progress or a decisive action; keep supporting information quiet.
- **Shape and imagery:** Favor one memorable motif with simple geometry. Carry it from icon to empty state and celebratory moments without repeating it on every control.
- **Motion:** Animate a meaningful state change, completion, or transition. Make the end state readable without animation and let repeated work stay calm.
- **Copy and feedback:** Be warm and specific. Say what was completed, saved, or needs attention. Pair a brief haptic or sound with a meaningful event only where the platform supports it.
- **Density:** Give a first-time task room to breathe. Let experienced users reach repeated actions quickly through the platform's normal menus, shortcuts, or controls.

## Review in a real app

Preview the same core task before, during, and after success. Check whether the accent still points to the right action when a warning appears, whether motion competes with content, and whether large text or Reduce Motion changes the emotional tone without hiding the result. Record screenshots and observations in `docs/design/NATIVE-REVIEW.md`.
