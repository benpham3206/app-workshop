# Calm / Precise

Use this recipe when clarity, confidence, and sustained attention matter. Express it through strong hierarchy, restrained accent use, spacious content, direct copy, and subtle feedback. Keep standard platform controls recognizable.

Before implementation, define semantic colors for applicable appearances and increased contrast, typography for long and short text, motion durations, haptics, icon treatment, and a Reduce Motion equivalent. Avoid hiding important state behind understated styling.

## Working grammar

- **Hierarchy:** Make the primary fact, task, and action easy to scan. Use alignment and type weight before adding decoration.
- **Color and material:** Reserve accent for a clear decision or status. Keep content surfaces quiet and use system materials for navigation and controls where appropriate.
- **Motion:** Prefer short transitions that preserve orientation. A settled state should feel complete without a persistent animation.
- **Copy and feedback:** Use plain, exact language. Confirm what changed and make recovery steps explicit when a task fails.
- **Density:** Allow sustained reading or editing without visual interruption. Keep frequent commands available through native platform patterns.

## Review in a real app

Inspect the primary task at first use, in a long session, and after an error. Check that restraint has not hidden the next action, selection, focus, or warning. Review small and large windows, large text, and increased contrast; record the evidence in `docs/design/NATIVE-REVIEW.md`.
