# visionOS profile

Start with a comfortable window for ordinary UI. Use volumes or immersive space when spatial presentation adds value. Plan for eyes and hands, comfortable placement, and minimal physical effort.

Use native window and control materials appropriate to visionOS, keeping content readable in changing surroundings. Measure launch, interaction response, memory, and sustained rendering on the supported headset; Simulator review does not establish comfort or thermal behavior.

Source checked 2026-09-25: [Apple spatial layout](https://developer.apple.com/design/human-interface-guidelines/spatial-layout/), [interface fundamentals](https://developer.apple.com/documentation/technologyoverviews/interface-fundamentals).
