# watchOS profile

Favor glanceable information and targeted actions that take a few taps. Evaluate complications, Smart Stack widgets, notifications, and a focused app separately. A paired iPhone Live Activity can appear in the Smart Stack without becoming a Watch widget.

Keep system materials and controls native and legible at small sizes. Treat launch, glance latency, memory, and battery as constraints on physical Watch hardware; test standalone and paired paths that the product actually offers.

Source checked 2026-09-25: [Apple Watch design guidance](https://developer.apple.com/design/human-interface-guidelines/designing-for-watchos), [Live Activities](https://developer.apple.com/design/human-interface-guidelines/live-activities).
