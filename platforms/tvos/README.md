# tvOS profile

Design for viewing at a distance, remote and controller input, and directional focus. Ensure every action has an obvious focus and selection state. Add tvOS only when the eventual app has a living-room use.

Let supported system controls and focus effects adapt to the current tvOS appearance. Check contrast over moving media and remote focus before adding custom glass. Measure navigation response and media-heavy screens on the oldest Apple TV class the product supports.

Source checked 2026-09-25: [Apple TV design guidance](https://developer.apple.com/design/human-interface-guidelines/designing-for-tvos), [focus and selection](https://developer.apple.com/design/human-interface-guidelines/focus-and-selection/).
