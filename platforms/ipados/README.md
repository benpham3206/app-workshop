# iPadOS profile

Design for freely resizable windows, multitasking, touch, keyboard, pointer, and Apple Pencil where useful. Keep layouts stable while resizing, with deliberate narrow-window behavior.

Use native glass navigation and controls on supported OS versions. Check legibility and interaction while windows resize and content moves beneath controls. Measure the core journey at narrow and wide sizes on representative iPad hardware, including keyboard and pointer paths if offered.

Source checked 2026-09-25: [Apple layout guidance](https://developer.apple.com/design/human-interface-guidelines/layout), [interface fundamentals](https://developer.apple.com/documentation/technologyoverviews/interface-fundamentals).
