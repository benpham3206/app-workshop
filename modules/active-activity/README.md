# Active Activity module

Use for an actual event or task with a beginning and end. The future app defines the state and update source. ActivityKit starts, updates, and ends an iPhone or iPad Live Activity; a WidgetKit extension supplies its presentations. The system may show it on a paired Watch Smart Stack, Mac menu bar, or CarPlay. A persistent widget or Watch complication is a separate module.

Before implementation, specify: start and stop triggers; concise public status; compact, minimal, expanded, and Lock Screen views; optional Watch and CarPlay layouts; deep links; update cadence; permission and availability handling; privacy redaction; and test cases. Do not use the surface for advertising or assume continuous display.

Source checked 2026-09-25: [ActivityKit](https://developer.apple.com/documentation/ActivityKit), [Live Activities design](https://developer.apple.com/design/human-interface-guidelines/live-activities).
