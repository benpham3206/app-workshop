# First launch and feature discovery

Choose the shortest path to a first useful result. Begin with the task itself when the interface can teach its use. Add a short onboarding flow only when a real prerequisite or unfamiliar interaction makes the task unclear. Let people skip optional instruction and find it later from Help or the relevant feature.

Make the result visible before offering advanced setup. Prefer a useful default over a configuration screen. Use a small contextual tip for a feature discovered later; keep it anchored to that feature. If a required resource needs a download, show what is available now and make progress and recovery clear.

Preview a fresh install, returning user, interrupted setup, large text, screen reader, and an unavailable network. Measure time to the first result rather than counting screens alone. Check that instructional copy never promises a capability unavailable on the selected platform.
