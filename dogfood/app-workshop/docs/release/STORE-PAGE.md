# Store presence

Fill this for the real app and each chosen storefront. App Store Connect requires a matching app record before a build can be uploaded. A Mac app distributed directly needs its own signing, notarization, delivery, payment, and update plan instead.

| Field | Decision and evidence |
| --- | --- |
| App name, subtitle, category, keywords | Pending |
| Name clearance and public seller name (individual legal name or organization legal entity) | Pending |
| One-sentence promise and description | Pending |
| Screenshots and app previews for selected platforms | Pending |
| App icon and version artwork | Pending |
| Privacy policy and support URL | Pending |
| Age rating, regions, languages, accessibility information | Pending |
| Pricing, IAP products, and subscription terms if any | Pending |
| Review notes, account or demo access, test instructions | Pending |
| Export compliance and applicable category rules | Pending |
| EU trader status and public contact details if EU storefronts are selected | Pending |

Drafts and hosting steps for the privacy policy, support, and Terms of Use pages are in `docs/legal/README.md`.

Check metadata against the actual build and supported devices. Run the reviewer path from a clean install. Keep screenshots truthful to the submitted version.

Apple references: [App Store Connect workflow](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-workflow), [create an app record](https://developer.apple.com/help/app-store-connect/create-an-app-record/add-a-new-app), [submit an app](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/submit-an-app). Reviewed 2026-09-25.

Clear names and assets before committing to the app record; Apple can reject misleading or infringing names. An individual or sole proprietor appears under a personal legal seller name; a DBA is not accepted as an organization seller. For EU availability, confirm trader status and the contact details Apple displays. [App Review Guidelines §4.1 and §5.2](https://developer.apple.com/app-store/review/guidelines/), [program enrollment](https://developer.apple.com/help/account/membership/program-enrollment/), [EU trader status](https://developer.apple.com/news/?id=einwn76m) (checked 2026-09-27).
