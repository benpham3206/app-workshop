# macOS profile

Plan for resizable windows, menus, keyboard commands, pointer interaction, and a platform-appropriate Settings scene. Decide whether a native Mac app, Mac Catalyst, or iOS app on Mac fits the eventual product.

Use native sidebar, toolbar, and sheet materials on supported OS versions before adding custom glass. Review contrast, focus, and resizing with pointer and keyboard. Measure the core journey on representative supported Mac architectures and window sizes; a build for one CPU does not prove the other.

Source checked 2026-09-25: [Apple windows guidance](https://developer.apple.com/design/human-interface-guidelines/windows), [multiplatform targets](https://developer.apple.com/documentation/xcode/configuring-a-multiplatform-app-target).
